# Button groups

[Material component specifications](https://m3.material.io/components/button-groups/specs) · [Versioned dimension source](https://m3.material.io/_dsm/data/dsdb-m3/2026-11-18_15-40-01/TOKEN_TABLE.082d7fd6e058b011.json)

Distinguish standard from connected groups. Standard inter-button padding is 18 / 12 / 8 / 8 / 8 dp for XS through XL. Connected groups use 2 dp between segments at every size. Check the 48 dp target for extra-small and small controls independently of the visible container.
