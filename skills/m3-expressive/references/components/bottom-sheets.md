# Bottom sheets

[Material component specifications](https://m3.material.io/components/bottom-sheets/specs) · [Versioned dimension source](https://m3.material.io/_dsm/data/dsdb-m3/2026-11-18_15-40-01/TOKEN_TABLE.75e530a1014802b3.json)

Apply the 640 dp width cap. Above that window width the spec describes 56 dp side and top margins. Record available window space as well as the rendered sheet.

## Measurements

| Attribute | Value |
| --- | --- |
| Drag handle padding top/bottom | 22dp |
| Top margin | 72dp |
| Top margin (window width > 640dp) | 56dp |
| Start/end margin (window width > 640dp) | 56dp |
| Width | Full width, up to max-width 640dp |
