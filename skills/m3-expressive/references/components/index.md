# Component dimensions

Select the component by its interaction and content. The official [component directory](https://m3.material.io/components) includes an [All buttons](https://m3.material.io/components/all-buttons) chooser spanning [button-groups](button-groups.md), [buttons](buttons.md), [extended-fab](extended-fab.md), [fab-menu](fab-menu.md), [floating-action-button](floating-action-button.md), [icon-buttons](icon-buttons.md), [segmented-buttons](segmented-buttons.md), [split-button](split-button.md).

Each sheet links the public specification and its versioned token data. Measurements tables preserve source units, minimums and ranges. Token rows give defaults for the named family, size and state. Join prefix and suffix with a period. Typography composites list font size, line height and tracking in that order. The database labels typographic points as POINTS; use the platform’s type-scale mapping before comparing them with CSS, sp or native points. Named contexts qualify values where they differ. Deprecated tokens are omitted. Baseline variants remain identifiable where Material distinguishes them.
